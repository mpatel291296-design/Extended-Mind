# Extended Mind (Pocket Mind)

A calm, phone-first second brain. Dump thoughts, screenshots, photos, doodles and files; Claude turns them into a few clear ideas you can keep, put on your desk, or let go.

**Open it:** https://mpatel291296-design.github.io/Extended-Mind/ (works in any phone browser; use "Add to Home Screen").

## Privacy
- This repo holds only the website code. It contains no personal data.
- Your ideas and photos sync to a separate **private** repo you choose, using a GitHub token stored only in your browser.
- Claude reads dumps with your own Anthropic API key, also stored only in your browser.

## First-time setup (on each device)
1. Open the site → **Set up Pocket Mind**.
2. **Anthropic API key**: console.anthropic.com → API keys.
3. **Private data repo**: `mpatel291296-design/pocket-Mind`.
4. **GitHub token**: GitHub → Settings → Developer settings → Fine-grained tokens → only the data repo → *Contents: Read and write*.
5. **Save and check.** Then do the same on your other devices to sync.

Works without keys too (saved on the device only, not read by Claude).
